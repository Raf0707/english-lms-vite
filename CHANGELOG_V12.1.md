# English LMS Frontend V12.1

This release is intentionally based on **Frontend V12**, not the later V13 branch.

- Admin dashboard buttons are backed by real API actions: refresh overview, course moderation, users, system checks, retry failed queues, backup snapshot.
- Notification items support backend action paths and navigate on click.
- Notifications refresh every minute and when the browser window regains focus.
- Teacher course editor supports access mode and course completion deadline.
- Assignment editor supports homework deadline.
- Added managed-course access screen for granting/revoking student access.
- Teacher course list exposes managed access controls.
- Public-free courses can be enrolled into without payment.
- Managed courses are not opened as public catalog products.
