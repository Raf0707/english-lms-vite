# Frontend V13

- All administrator actions are connected to backend operations; moderation now includes direct “return for revision”.
- Notification popover supports action links and refreshes periodically/on focus.
- Managed course access screen for teachers: grant/revoke student access by email/phone and optional expiration.
- Course editor supports access mode (paid/free/managed), course completion deadline and assignment due dates.
- Free public course enrollment is connected to backend.
- Managed courses are not treated as public-sale courses and expose access management only to their teacher.
- Student/teacher notification navigation is wired to relevant workspace tabs.
