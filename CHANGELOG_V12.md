# Frontend V12

## Исправления

- Добавлены нормальные внутренние отступы каталога внутри кабинета ученика на desktop и mobile.
- В карточках каталога отображается реальное количество участников курса из backend.
- Rich-text редактор переработан для точного применения `font-size`/`font-family` только к выделенному тексту.
- Live DOM редактора больше не пересоздаётся после каждой команды форматирования: курсор и выделение не прыгают, а размер текста не «съезжает».
- Редактор и страница урока используют одинаковую базовую типографику и одинаковую line-height для фрагментов с пользовательским размером.

## Дальнейшее подключение backend

- Убрана зависимость публичной главной и страницы курса от demo-курсов: опубликованные курсы загружаются из API.
- Глобальный поиск использует реальные публичные курсы ученика и реальные managed courses преподавателя/администратора.
- Подключены реальные словарь/SM-2, расписание, бронирования, история платежей и уведомления.
- Подключены реальные тестовые попытки и серверная проверка тестов.
- Подключены отправка/проверка домашних заданий, включая файлы.
- Подключены реальные ученики преподавателя и административные пользователи/заказы/финансовая сводка.
- Добавлена прямая загрузка файлов уроков и обложек курса в S3/MinIO через signed PUT URL.
- Медиа уроков и обложки после F5 заново получают короткоживущие signed GET URL.
- Публичные карточки курсов получают обложку только через безопасную публичную ручку опубликованных course covers.
- Локальные backend-backed сущности больше не сохраняются в localStorage между аккаунтами.
