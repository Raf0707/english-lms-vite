# V11

- Покупка курса переведена с локальной имитации на backend Order -> Payment -> Enrollment.
- После mock-оплаты frontend перечитывает /me/enrollments и enrollment-specific версию курса.
- «Моё обучение» восстанавливается из backend после входа/обновления страницы; локальные enrollment больше не персистятся между пользователями.
- Завершение урока сохраняется через backend.
- Исправлены курсив и зачёркивание в rich-text редакторе.
- Выравнивание частично выделенного текста больше не изменяет весь абзац: выделенный фрагмент получает собственное выравнивание.
