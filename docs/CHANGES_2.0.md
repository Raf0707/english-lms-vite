# Изменения версии 2.0

В эту ревизию включены исправления после проверки первого frontend-прототипа.

## Авторизация и профиль

- Номер телефона обязателен при регистрации.
- Вход поддерживает Email или номер телефона.
- Телефон хранится в профиле и редактируется.
- Профиль доступен ученику, преподавателю и администратору.

## Навигация и поиск

- В публичную верхнюю панель добавлена явная кнопка «Главная».
- Глобальный поиск в кабинете ищет разделы, курсы и занятия.
- Для преподавателя поиск ограничен его курсами, для ученика — опубликованными курсами.
- Поиск в каталоге и административных списках работает по соответствующим полям.
- Левую панель можно свернуть до иконок и развернуть обратно; состояние сохраняется.

## Конструктор курсов

- Создание и редактирование курса для преподавателя и администратора.
- Основные данные: название, описания, уровень, категория, цена, старая цена, длительность, URL, теги, результаты обучения и обложка.
- Иерархия «модуль → урок → контентные блоки».
- Типы уроков: текст, видео, практика, тест, домашнее задание, видеоконференция.
- Контентные блоки: заголовок, форматируемый текст, таблица, видео, файл, тест, домашнее задание, конференция, цитата, выделенный блок.
- Для текста доступны размер, жирность, курсив, подчёркивание, выравнивание, маркированный и нумерованный список.
- Редактор таблиц поддерживает добавление строк и колонок.
- Загрузка обложки, видео, аудио, изображений и файлов в frontend-демо.
- Конструктор тестов: одиночный/множественный выбор, текст, эссе; авто- и ручная проверка.
- Домашнее задание: текстовый/файловый ответ, авто- или ручная проверка, максимальный балл.
- Ручные домашние задания реально попадают в очередь преподавателя; преподаватель может принять работу, поставить балл или вернуть её на доработку.
- Расписание курса: открытие уроков по времени и живые конференции.
- Конференции курса автоматически синхронизируются с общим расписанием после сохранения курса.
- Преподаватель отправляет курс на модерацию; администратор публикует или возвращает его на доработку с комментарием.
- Преподаватель не может редактировать курс другого преподавателя.

## Отдельные занятия

- Публичный и авторизованный каталог преподавателей.
- Поиск преподавателя и фильтр «индивидуальные / групповые».
- Просмотр свободных слотов и стоимости.
- Бронирование отдельного занятия, не связанного с курсом.
- После бронирования занятие появляется в расписании, платёж — в истории.
- Преподаватель может создавать отдельные индивидуальные, групповые занятия и вебинары.
- Преподаватель может публиковать собственные свободные окна для самостоятельной записи учеников; новые слоты сразу появляются в каталоге преподавателей.

## Видеоконференция

- Исправлена сетка превью конференции на лендинге.
- Элементы управления имеют фиксированные размеры, сетка не вылезает за контейнер на узких экранах.
- Добавлена ссылка на выбор преподавателя из секции живых занятий.

## Важно о frontend-демо

Загрузка медиа использует браузерный локальный URL для предпросмотра. Для production необходимо подключить API/S3/HLS, указанные в техническом задании. Аналогично платежи, реальный WebRTC/SFU, серверная аутентификация и серверная проверка тестов должны выполняться backend-сервисами.
