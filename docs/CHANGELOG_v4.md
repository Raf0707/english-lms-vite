# English LMS — изменения 4.0.0

Реализованы правки очередной итерации интерфейса и редактора курсов:

- пустое состояние поиска «Моё обучение» с отступом 30 px и заголовком в одну строку с иконкой;
- календарь показывает время и название мероприятия, увеличены заголовок месяца и блок часового пояса;
- увеличена типографика карточек преподавателей;
- минимальный размер любого явно заданного текста в CSS — 12 px;
- поиск каталога учитывает название, уровень, категорию/направление, преподавателя и теги;
- убрано озвучивание всего урока, добавлено озвучивание каждого текстового блока и выделенного фрагмента;
- изображения, видео и аудио отображаются в уроке; аудио можно загрузить или записать с микрофона;
- файлы можно перетаскивать в урок, формат определяется автоматически;
- модули, уроки и блоки перемещаются drag-and-drop и стрелками вверх/вниз;
- модули, уроки и блоки копируются/вставляются целиком через внутренний и системный буфер;
- поле тегов не уничтожает запятые во время ввода;
- преподаватель отправляет запрос на удаление собственного курса, администратор подтверждает/отклоняет его;
- администратор может удалить курс напрямую;
- меню «…» в разделе пользователей администратора стало рабочим;
- исправлена раскладка статусов резервного копирования.

## Проверки

- Все TS/TSX-файлы разобраны TypeScript parser без синтаксических ошибок.
- В CSS не осталось явных `font-size` в пикселях меньше 12 px.
- Полный `npm install` в рабочей среде выполнить нельзя: внутренний npm registry не содержит требуемую версию `@types/node@22.10.2`. На обычной машине с доступом к npm проект запускается стандартными командами из README.
