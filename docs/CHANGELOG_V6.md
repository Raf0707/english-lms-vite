# V6 changes

- Compact lesson TTS controls now toggle between the speaker icon and a red stop square on the exact fragment being spoken.
- English text selection expands to complete word boundaries; translation popup opens at the pointer, is clamped to the viewport and can be dragged.
- Course editor drag-and-drop was rebuilt around dedicated draggable handles and a synchronous drag reference for modules, lessons and blocks. Arrow controls remain as a fallback.
- Backup status block is displayed as a compact vertical list without the previous tile grid and with overflow-safe status labels.
